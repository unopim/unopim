# Design system
INLINE_STYLE~\.(blade\.php|vue)$~style="~Inline styles bypass the design tokens and dark mode. Use Tailwind classes.
STYLE_BLOCK~\.(blade\.php|vue)$~<style~A <style> block bypasses the design system. Put styles in Tailwind classes.
HEX_COLOR~\.(blade\.php|vue|js)$~#[0-9a-fA-F]{3,8}\b~A hex colour cannot follow the .dark CSS variable swap, so dark mode breaks visibly. Use primary, success, warning, danger or info.
RGB_COLOR~\.(blade\.php|vue|js)$~rgba?\(~A colour literal cannot follow the .dark variable swap. Use a semantic token.
TAILWIND_INTENT~\.(blade\.php|vue|js)$~\b(violet|purple|fuchsia|indigo|red|green|emerald|blue|amber)-(50|[1-9]00)\b~Default Tailwind scales are not themable. Use primary, primary-hover, success, warning, danger or info.
LEGACY_TOKEN~\.(blade\.php|vue|js)$~unopim-primary-~unopim-primary-* is baked hex and cannot be re-skinned by integrators. Use the semantic primary token.
# Components
RAW_FORM_CONTROL~Resources/views/(?!components/form/).*\.blade\.php$~<(input|select|textarea|label)\b~An x-admin::form.control-group component exists for this. Raw controls skip validation display, labels and styling.
RAW_TABLE~Resources/views/(?!components/).*\.blade\.php$~<table\b~x-admin::datagrid or x-admin::table renders listings. A hand-rolled table loses search, filters, sorting and mass actions.
RAW_MODAL~Resources/views/(?!components/).*\.blade\.php$~(role="dialog"|aria-modal)~x-admin::modal exists. A hand-rolled dialog loses focus trapping and close behaviour.
# Comments
INLINE_COMMENT~\.(php|js|vue)$~^\s*//~Inline comments are not used in this codebase. Put a one-line why in the PHPDoc, or leave it out.
BLADE_COMMENT~\.blade\.php$~\{\{--~Blade comments explaining markup are not used. Remove it.
BANNER_COMMENT~\.(php|js|vue|blade\.php)$~(//\s*={4,}|//\s*-{4,}|/\*\s*={4,}|/\*\s*-{4,}|#region)~Banner and divider comments are noise. Delete it.
# Validation and mass assignment
INLINE_VALIDATE~\.php$~(\$request|request\(\))->validate\(~Inline validation is not used. Type-hint a FormRequest class.
GUARDED_EMPTY~\.php$~\$guarded\s*=\s*\[\s*\]~An empty $guarded opens every column to mass assignment. Declare $fillable.
DB_RAW_INTERPOLATION~\.php$~DB::raw\([^)]*\$~A variable interpolated into raw SQL. Use bindings. DB::rawQueryGrammar() is a UnoPim JSON-path helper and is not this rule.
# Scale
MODEL_ALL~\.php$~::all\(\)~Unbounded reads do not scale to millions of rows. Use paginate(), chunkById() or lazyById().
BLADE_QUERY~\.blade\.php$~(DB::table\(|::where\(|Repository::|app\(.+Repository)~Queries do not belong in views. Fetch in the controller or a view composer and pass data in.
# CRUD pattern
GET_CREATE_ROUTE~Routes/.*\.php$~Route::get\((['\"])[^'\"]*create~Create is a code+label modal on the index page and store() redirects to edit. Do not add a GET create page route.
